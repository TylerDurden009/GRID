Chapter 1 — Introduction to Web Development

1.1 Internet vs WWW

Definition: The Internet is a global network of interconnected computers using TCP/IP. The World Wide Web (WWW) is an information system of linked web pages that runs on top of the Internet via HTTP.

Hinglish: Internet = sadak (infrastructure). WWW = us sadak par chalti gaadi (service). Email, FTP, VoIP bhi Internet par chalte hain, par web nahi hain.

FeatureInternetWWW
TypeInfrastructureInformation service
Born1969 (ARPANET)1989 (Tim Berners-Lee)
Browser neededNoYes

1.2 Frontend vs Backend

  • Frontend — HTML, CSS, JS. Jo user dekhta hai (showroom).
  • Backend — Server, database, logic (Node.js, Python, Java). Godown + manager.

1.3 What is HTML?

Definition: HTML (HyperText Markup Language) is a markup language used to structure content on the web. It is not a programming language — no variables, loops, or logic.

Hinglish: HTML = structure. CSS = style. JavaScript = behaviour. House analogy: HTML = deewarein, CSS = paint, JS = bijli.

Void elements (no closing tag): <br>, <hr>, <img>, <input>, <meta>.

1.5 HTML Versions

HTML 1.0 (1991) → HTML 4.01 (1999) → XHTML (2000) → HTML5 (2014) → HTML Living Standard (ongoing).

Chapter 11 — Introduction to CSS

11.1 What is CSS?

Definition: CSS (Cascading Style Sheets) describes the presentation of HTML — layout, colour, typography, animation. Separates content (HTML) from presentation (CSS).

11.2 Syntax

selector {
    property: value;
}

Formula: "Kisko (selector) → Kya (property) → Kaise (value)".

11.3 Three Ways

1. Inline (not recommended):

<p style="color: blue;">Text</p>

2. Internal:

<head><style>p { color: green; }</style></head>

3. External (best):

<link rel="stylesheet" href="styles.css">

11.4 Cascade

Priority (high to low): !important > inline > ID > class > element > *.

Memory trick: Id Class Element — ICE.

Chapter 15 — Box Model

15.1 The Four Layers

┌──────────────────────────────┐  ← Margin
│  ┌─────────────────────────┐ │  ← Border
│  │  ┌────────────────────┐ │ │  ← Padding
│  │  │      CONTENT       │ │ │
│  │  └────────────────────┘ │ │
│  └─────────────────────────┘ │
└──────────────────────────────┘

Analogy: Content = gift, padding = bubble wrap, border = box, margin = space between boxes.

15.2 All Properties

.box {
    width: 200px;
    height: 100px;

    /* TRouBLe: Top Right Bottom Left */
    padding: 10px 20px 30px 40px;

    border: 2px solid #333;

    /* auto = horizontal center */
    margin: 16px auto;
}

15.3 box-sizing — The Critical Fix

content-box (default): width excludes padding + border.
border-box: width includes padding + border.

Global reset (industry standard):

*, *::before, *::after {
    box-sizing: border-box;
    margin: 0;
    padding: 0;
}

15.4 Margin Collapse

Vertical margins of adjacent blocks collapse to the larger value:

.a { margin-bottom: 30px; }
.b { margin-top: 20px; }
/* Gap = 30px, not 50px */

Horizontal margins do not collapse.

18.3 z-index

Only works on positioned elements. Higher = in front.

Common mistakes:

  1. Absolute child doesn't stay in parent → parent needs position: relative
  2. z-index doesn't work → element has position: static
  3. Sticky doesn't work → no top/left set, or parent has overflow: hidden

Chapter 19 — Flexbox

19.1 Concept

Flexbox is a 1D layout — arranges items in a row OR column.

  • Main axis = direction items flow (row default)
  • Cross axis = perpendicular

19.2 Container Properties

.container {
    display: flex;

    flex-direction: row;
    /* row | row-reverse | column | column-reverse */

    flex-wrap: wrap;   /* nowrap | wrap | wrap-reverse */

    justify-content: center;
    /* main axis: flex-start | flex-end | center |
       space-between | space-around | space-evenly */

    align-items: center;
    /* cross axis: stretch | flex-start | flex-end | center */

    gap: 16px;
}
Memory: justify-content = main axis. align-items = cross axis.

19.3 Item Properties

.item {
    flex: 1;                /* shorthand for 1 1 0% */
    flex-grow: 1;
    flex-shrink: 1;
    flex-basis: auto;

    align-self: flex-end;
    order: 2;
}

19.4 Classic Centering

    display: flex;
    justify-content: center;
    align-items: center;
    min-height: 100vh;
}

19.5 Navbar

Chapter 20 — Grid

20.1 Concept

Grid is a 2D layout — rows AND columns simultaneously. Best for page layouts, galleries, dashboards.

Rule of thumb: Grid for layout, Flexbox for components.

20.2 Container Properties

.container {
    display: grid;

    grid-template-columns: 200px 1fr 2fr;
    grid-template-columns: repeat(3, 1fr);
    grid-template-columns: repeat(auto-fit, minmax(220px, 1fr));
    /* ↑ responsive magic */

    grid-template-rows: 80px auto 80px;

    gap: 20px;
    gap: 20px 12px;   /* row column */
}

20.3 grid-template-areas (Killer Feature)

.dashboard {
    display: grid;
    grid-template-columns: 220px 1fr;
    grid-template-rows: 70px 1fr 50px;
    grid-template-areas:
        "header  header"
        "sidebar main"
        "footer  footer";
    height: 100vh;
}

.header  { grid-area: header; }
.sidebar { grid-area: sidebar; }
.main    { grid-area: main; }
.footer  { grid-area: footer; }

Layout written as ASCII art — extremely readable.

20.4 Item Properties

.item {
    grid-column: 1 / 3;
    grid-column: 1 / span 2;
    grid-row: 2 / 4;

    grid-area: header;
    grid-area: 1 / 2 / 3 / 4;

    justify-self: center;
    align-self: end;
}

20.5 auto-fit vs auto-fill

/* auto-fit: collapses empty tracks, items stretch */
grid-template-columns: repeat(auto-fit, minmax(220px, 1fr));

/* auto-fill: keeps empty tracks */
grid-template-columns: repeat(auto-fill, minmax(220px, 1fr));
The one-line responsive grid: grid-template-columns: repeat(auto-fit, minmax(250px, 1fr)); — auto-arranges 1, 2, 3, 4+ columns. Zero media queries.

Chapter 25 — Best Practices

25.1 Clean Code

  • One declaration per line
  • Consistent indentation
  • Meaningful class names (BEM)
  • No !important

25.2 Performance

  1. Minify CSS (Vite, PostCSS)
  2. Critical CSS inline in <head>
  3. Animate transform/opacity (GPU)
  4. Cache-busting filenames (main.a3f5.css)
  5. Optimize images + srcset

25.3 Accessibility Checklist

  • Colour contrast: WCAG AA = 4.5:1 for text
  • Focus styles: never outline: none without replacement
  • Zoom-friendly: use rem/em
  • Reduced motion: @media (prefers-reduced-motion)
  • Dark mode: @media (prefers-color-scheme: dark)

25.4 Debugging with DevTools

  1. F12 → Elements tab
  2. Inspect arrow → click element
  3. Right panel: Computed, Styles, Box Model
  4. Toggle states: :hov → :hover, :focus, :active
  5. Grid/Flex overlays — click badge next to display
  6. Coverage — unused CSS
